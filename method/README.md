# Method

The portable method lives in [doctrine](doctrine/): [WORKFLOW](doctrine/WORKFLOW.md),
[PRINCIPLES](doctrine/PRINCIPLES.md), [GATES](doctrine/GATES.md), [TOOLCHAIN](doctrine/TOOLCHAIN.md)
and the [decision records](doctrine/decisions/). [ADR 0005](doctrine/decisions/0005-harness-framework-identity.md)
authorizes this canonical home. It changes organization, not the lifecycle or route authority.

The method validators and receipt vocabulary live in `tools/harness/` and `tools/gates/`.
Root profiles and public core package paths remain stable. Run templates live in
[run-record/templates](../run-record/README.md); completed `.llm/runs/` records remain unchanged.

Canonical invocations from the checkout root:

```sh
node method/tools/harness/matrix-receipts.mjs receipt.json
deno task harness:milestone:render -- <run-dir>
deno task harness:milestone:validate -- <run-dir> --github-prs <export.json>
pnpm run check:method
```

Milestone commands require Deno 2. CI installs the version declared in its workflow and executes
both canonical and legacy paths cold, including exit propagation. Node package lifecycle commands
retain the Node/pnpm toolchain; `check:method` also requires Deno. No compile output is required to
invoke these source tools.

[The path map](path-map.json) names all 26 moved files. Former doctrine pages retain anchor
navigation to the canonical document; old modules, test commands and CLIs delegate explicitly.
The ten legacy template files are generated byte-identical copies, including JSON consumed directly
by callers. Edit canonical files, then run `node scripts/method-compatibility.mjs --write` from the
checkout root. The read-only check refuses stale copies, missing delegation and broken invocation.

Generated milestone status retains its `.llm/tools/harness/render-milestone-status.ts` provenance
header. That path remains a working compatibility entrypoint. Keeping the header preserves exact
validation of completed records; it does not create a second renderer or relax stale/source checks.
Legacy aliases have no retirement date until the measured caller census permits their removal.
