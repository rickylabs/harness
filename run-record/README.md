# Run record

[Templates](templates/) are the canonical starting artifacts for a run or milestone cluster.
The [method](../method/README.md) defines the lifecycle; profiles remain at the repository root.
This home is a template organization change, not a persistence or checkpoint implementation.

Completed committed evidence stays byte-identical under `.llm/runs/`. New run evidence uses the
location authorized by its brief and host layout; moving templates does not relocate completed
records or create a new storage authority.

The inherited plan and supervisor templates refer to target-project facts. An archetype guide,
doctrine verdict or routing authority must be cited from that project when applicable; Harness
supplies no local NetScript archetype/lane-policy catalog. N/A and unproven remain honest outcomes.

Legacy `.llm/harness/templates/` files are generated byte-identical compatibility copies for callers
that read template data directly. Edit the canonical template, then run
`node scripts/method-compatibility.mjs --write` from the checkout root. `pnpm run check:method`
checks copies, delegates and actual old/new tool invocations. The milestone status template and
renderer retain the working legacy provenance header to preserve historical byte parity.
