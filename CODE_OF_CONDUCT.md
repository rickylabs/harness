# Code of conduct

This repository adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
by reference. Copying five kilobytes of it into a repository with one owner would not make the
standard any more binding; the link is the standard.

The short version: be decent, assume good faith, disagree about the work rather than about the
person, and accept that the owner decides.

## Reporting

Report anything to the owner, [@rickylabs](https://github.com/rickylabs), privately. Reports are
handled by the owner because there is currently no one else — if that changes, so does this file and
[`GOVERNANCE.md`](GOVERNANCE.md).

## One thing worth stating explicitly

Agents write most of the content here — issue bodies, review comments, pull request descriptions.
**An agent's output is its operator's responsibility.** Dispatching a run does not launder what the
run says, and "the model wrote it" is not a defence for anything this document would otherwise
cover.
