# Test the producer and the deployed decoder together

A native rewrite can preserve wire types while silently dropping metadata or making every frame
incomplete. Keep facet assertions on the actual producer, verify both default and opt-in coverage,
and run real frames through the older tagged decoder. A duplicate test collector certifies itself
while production behavior drifts; sharing the production metadata path exposes that drift.

Native current state and historical metadata have different authority. Keep the original certified
receipt object for private store identity, while projecting current execution from the native proof.
A spread receipt does not inherit the host's private identity registry. Batch exact receipt reads
without letting retained history choose live roots. Resource or compile failures remain inconclusive.
