A restored workspace label and the agent-native session ID select the existing run; current Herdr integration state supplies execution; Orchid's completion fence supplies final assignment end. Receipt age, file freshness and an idle turn cannot substitute for those signals.

Bound selection at the native current census and transport packet. Retained history must not choose which active keys are read. Reuse the existing durable stream/KV writer and content deduplication, with native events as invalidations and prepared reads on the Home request path. When the upstream primitive is missing, expose it upstream and name the dependency instead of reconstructing it in a consumer.

A stale paired stop cannot override fresh native execution: stop and teardown files persist across resume while the run continues, so the producer strips them and proves liveness only from current Herdr state plus the Orchid final fence. Point-selected membership (exact keys through the locked reader) holds current roots without a bulk refresh; the checkpoint proposal carries coordinates only, and the consumer merges without clearing on failure.
