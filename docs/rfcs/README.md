# Design RFCs

New design work uses numbered files here and the EIS RFC shape: Status, Date, Scope, pinned
Evidence snapshot, Delivery tracking, Claim labels, Summary, Context and current state,
design sections, Consequences and Revisit triggers. Material claims are CURRENT, CITED,
PLANNED or MEASURED. A proposal is not a charter amendment or an acceptance receipt.

- [0001: First-class Layer 1 adoption](0001-first-class-layer-one.md) — proposed; existing
  capabilities, ownership boundaries and the next executable proofs.

The [family charter](../../ARCHITECTURE.md) remains authoritative. Existing run artifacts
remain durable evidence; this index does not rewrite prior ratification or pilot history.
