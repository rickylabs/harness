## Repository leg

- `admit` walks transitive upstream gates but trusts supplied done states; `settle` validates declared citation shape and kind. Therefore a driver cannot treat an arbitrary `admitted: true` object, or hand-written done state, as sufficient evidence. Revalidate upstream completion through the existing settlement rule before assembling work. Preserve the distinction between existing routing admission and a future live governance channel.
