# issue-agent-feed--alpha — independent implementation review

**Final re-review verdict: PASS.** The revised source closes all four findings. The feed still has explicit integration limits: Orchid has not supplied proven route-default or child budgets, child router evidence is unavailable, and Cockpit owns durable replay. These are documented acceptance gates, not claims established by this review.

## Findings

1. **The decoder accepts inherited child budget and route claims.** The producer correctly sets a child budget to unavailable and a child router to unavailable (`packages/telemetry/src/issue-agent-feed.ts:33-58`). The public decoder validates `budget` and field source only as standalone shapes, then validates ancestry separately; it never compares those claims to the child's `known-parent` state (`packages/contracts/src/issue-agent-tree.ts:148-157,203-208,241-266`). A child row with `{tokenLimit:1000,source:"route-default",reason:null}` or a dispatch-sourced provider/model can pass while its native child has no attributed dispatch budget or route. That contradicts `plan-amendment.md:10` and the cockpit reply item 5. **Fix:** for this schema, reject sourced child budget/router and dispatch-sourced child identity unless a validated child evidence path exists; add negative decoder fixtures alongside the producer's root-budget/child-null test.
2. **Freshness is not enforced at emission.** The CLI takes `at` before the asynchronous scan, accepts any structurally valid snapshot and writes it after collection (`packages/telemetry/src/issue-agent-feed-cli.ts:93-107`). The collector builds `validUntil` from that pre-scan time (`packages/telemetry/src/issue-agent-feed-cli.ts:23-38`; `packages/telemetry/src/issue-agent-feed.ts:98-103`). A scan lasting more than 15 seconds can therefore emit `complete:true` with an already expired `validUntil`. The CLI also accepts a 60-second interval despite a 15-second validity period (`packages/telemetry/src/issue-agent-feed-cli.ts:58-72`), leaving a known stale source between frames. The cockpit reply item 2 requires missing/stale feed to be unknown. **Fix:** detect expiration against the clock immediately before write and emit an incomplete frame with a typed reason or collect at completion; bound watch interval to the freshness promise. Test a delayed collector and interval rejection.
3. **The public-safe label permits path-shaped values.** `safe()` projects any native model/provider matching `[A-Za-z0-9._/-]` (`packages/telemetry/src/issue-agent-feed.ts:13-15,35-37`), and the decoder's shared `label()` accepts the same syntax for host/container/seat (`packages/contracts/src/issue-agent-tree.ts:124-146`). Thus a relative path such as `home/agent/private` passes as a model or placement value, although absolute-path canaries fail. The cockpit reply item 3 and the public repository brief prohibit operator paths. **Fix:** use source-specific validation for location display IDs and reject path-shaped native identity values before projection; add relative-path canaries. Preserve legitimate slash-bearing model IDs only under an evidence-backed model grammar or allowlist.
4. **Aborted native turns are reported as failed.** Codex backfill folds `turn_aborted` into `failed` with `error` and `stream_error` (`packages/telemetry/src/backfill/codex.ts:231-233`), and the new producer maps any `failed` run to `terminalOutcome.value:"failed"` (`packages/telemetry/src/issue-agent-feed.ts:39-47`). The cockpit explicitly asked for a distinct `cancelled` outcome (`the private cockpit contract reply (2026-09-27)`, item 4). The current `RunRecord` cannot distinguish abort from failure (`packages/telemetry/src/model.ts:25-26,132-143`). **Fix:** retain an attributable abort/cancellation classification in the private native read path, or report this ambiguous case as unknown rather than definitively failed. Add a `turn_aborted` fixture through the feed.
