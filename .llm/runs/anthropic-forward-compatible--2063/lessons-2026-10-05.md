Catalog updates cannot remove release lag. Test the owned public configuration through direct construction and registered factories, prove discovery offline and inspect the exact provider wire. Model admission alone cannot establish request compatibility. The tool regression also asserts request counts so an SDK internal loop cannot masquerade as a single owned turn.

Keep workspace graph, exact reported consumer graph and current unpinned consumer separate; all three can differ. Generate carrier assets with CI’s Deno version and commit them before tests that inspect detached HEAD. Use executable temporary storage for executable fixtures and native Git for tests that create worktrees.

Separate-vendor review needs actual isolation evidence. A launcher cwd is insufficient if tool arguments select another workdir; retain the deviation, repeat baseline/fixed proof in the assigned checkout and preserve the corrected verdict. Source PASS, package release, CLI E2E and paid provider inference are separate evidence claims.
