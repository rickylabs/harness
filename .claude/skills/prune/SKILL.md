# Prune

Delete, do not deprecate (golden rule 3). A dead file costs every reader time, and a compatibility
alias keeps it alive forever. The work is in proving the file is dead.

## Prove it is dead

An empty search proves nothing until you know every way the file can be reached. An import graph
misses files that are reached by a URL fork, by a `package.json` script, or by being read as data. So
search for the **basename** and for the **path**, across everything except `.llm/runs`:

    git grep -n -e '<basename>' -e '<repo/relative/path>' -- ':!.llm/runs'

Then check each place a file can be reached:

- `package.json` scripts (root and every `packages/*/package.json`, including `bin` and `exports`);
- `scripts/*.mjs`, especially `scripts/core-packages.mjs`, `scripts/check-links.mjs` and the
  `run-stages` stage lists;
- `.github/workflows/*.yml` steps and their comments;
- tests that spawn a file or read it as a fixture;
- `profiles/*.md`, `packages/forge` templates, `.claude/skills/*`, and every README or doc.

A file is dead only when each hit is gone or is in the set you are deleting too. A generated file is
regenerated by its command, never edited by hand ([`CONTRIBUTING.md`](../../../CONTRIBUTING.md) lists
them).

## Delete it properly

- Remove the file, its test, its fixture, its package script, its CI step, and every sentence that
  describes it, all in the same PR.
- No re-export shims, no aliases, no pointer pages, no commented-out code, no TODO stubs.
- Fix every doc the deletion makes untrue. The proof is a whole-repo `git grep` for each removed path,
  script name and package name, with the command and its empty result pasted in the PR body.
- Something stale outside your issue's scope: do not fix it; list it in the PR's Drift and debt.

## Never touch

- `.llm/runs/**` is owner-controlled. Never delete, move or rewrite anything under it, even when it names
  a path you removed. Check with `git diff --stat origin/main -- .llm/runs`; the result must be empty.
- A consumer surface in [`docs/STRUCTURE.md`](../../../docs/STRUCTURE.md#consumer-surfaces) is not
  dead because nothing in this repository imports it. Another repository does. See the
  [parity-tests skill](../parity-tests/SKILL.md).
